# Base nativa para Fashion Stylist AI

El landing y el Studio web permanecen como producto web independiente y no serán reemplazados. La aplicación nativa se construirá en un proyecto paralelo para Android e iOS, reutilizando el mismo lenguaje de marca y conectándose después a los contratos de perfil, armario y estilista ya establecidos.

| Plataforma | Entregable de desarrollo | Requisito externo para distribución |
| --- | --- | --- |
| Android | Proyecto Expo/React Native y compilación APK/AAB | Clave de firma o cuenta de distribución según el canal elegido |
| iOS | Proyecto Expo/React Native y paquete archivado | Cuenta activa de Apple Developer, identificador de paquete y firma de distribución |

No se publicará ni se enviará ninguna aplicación a tiendas sin la autorización explícita del titular de las cuentas correspondientes.
